# Cat_game

貓咪小屋的可執行成品。用瀏覽器開啟 `index.html` 就能玩。

- `index.html` + `game.js`:遊戲(室內小房間、室外草皮,點擊讓貓走過去,可縮放、換花色)
- `preview.html` + `preview.js`:全動作預覽(開發用)

啟用 GitHub Pages 後,網址是 https://hn84786349.github.io/Cat_game/

這個資料夾的內容由 [Cat_code](https://github.com/hn84786349/Cat_code) 的 `node tools/build.js` 產生,請不要直接修改。
